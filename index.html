沉没成本：同一笔钱，时间点不同，身份不同

上次讲成本时留下一个尾巴：投资前，这笔钱是机会成本；投资后，如果收不回来，它就变成沉没成本。这个“时间点”决定了它该不该进入今天的决策。

先把这句话记住：沉没成本不是“花掉的钱”，而是“已经花掉、且无法收回的钱”。同样的 200 万，站在投资前和投资后，是完全不同的两个东西。

“一笔钱投到一个不能收回的地方，在之前它是一个机会成本。比如专用设备或者广告，如果你觉得不合适，这钱是可以用在别处的。但是一旦你投入了，到了这个时间点之后，就变成沉没成本了。所以沉没成本这个概念，其实它是一个比较短期的一个概念。”

投资后：钱已经投进去且收不回来，全部变成沉没成本。它不该再影响“要不要继续”的决策；继续与否只看未来的增量收益和增量成本。
沉没成本 ≠ 固定成本

固定成本是“不随产量变化”的成本；沉没成本是“收不回来”的成本。厂房如果还能转租、设备还能转卖，它是固定成本，但不是沉没成本。

固定成本可以是机会成本

厂房、设备、其他资产如果能随时按市价卖出、退租或用于其他生产，那么固定成本没有“沉没”，它仍然是一项机会成本。

决策只看增量

已经收不回来的钱，不该再进入“继续还是停止”的比较。你只需要比较：继续干下去的未来收益，是否覆盖未来的增量成本。

生活版例子：刚买一瓶汽水或奶茶，走出店门，它的转售价值就损失了一部分。这部分损失是沉没成本；再为它纠结，只会继续耗费你的精力，而不会改变已经发生的损失。

这个区分不是文字游戏

它直接决定后面“停止生产点”画在哪里：如果固定成本可以收回，企业停产就能避免它，停止生产点应按 minATC 看；如果固定成本已经沉没，停产也躲不掉，短期只要价格覆盖平均可变成本（P ≥ minAVC）就值得继续生产。课件把这两种情形分开讨论，本页也会在供给曲线一节明确标注。

01

市场结构：定价权 × 进入自由

完全竞争不是“竞争很激烈”，而是一组关于定价权和进入退出的假设。把这两个维度交叉，就能得到四种市场结构。

第一个维度：企业能不能影响价格？能影响，是价格决定者；不能影响，是价格接受者。第二个维度：企业个数是外生给定的，还是可以自由进出？两个维度一交叉，完全竞争占据了表格里的两格——短期和长期。

价格接受者

单个企业相对于市场太小，它卖多少都改变不了市场价格。它面对的需求曲线是一条水平线：P = MR。

“小”是相对市场而言

不是绝对规模小，而是它的产量相对于市场规模很小。具体表现是：边际成本上升得很快，产量稍微大一点，成本就迅速上升，所以它很难做大。

没有全局规模经济

完全竞争企业的规模经济只存在于一个极小的范围，在平均成本最低点以下。超过最低点就进入规模不经济，所以它不可能靠扩大产量统治市场。

现实中哪里最接近？

农产品、黄金、部分化工原料和石油加工（汽油、柴油、煤油）比较接近：产品同质、买家多、单个企业小。煤矿也常被拿来举例，但煤价值低、重量大、运输成本高，运输成本会让它带有区域垄断性质——附近没有别的煤矿时，它并不是一个简单的价格接受者。黄金则更接近：不同金矿的采矿条件不同、成本不一样，但产出的黄金是一样的，而且价值高、运输成本相对低。

“同质企业”假设有多牵强？

课件说完全竞争企业有相同的技术、相同的团队，这个假设确实很强。现实中每个煤矿的成本都不同：有的煤要往地下挖 200 米才有，成本就高得多。但可以把低成本矿的租金从成本里扣掉，把成本差异归给资源所有者，从而把企业近似看成同质的。所以这个假设不算太牵强，但它是一个抽象，不是对现实的精确描述。

一个理论上的小麻烦：哪怕市场上只有 10 家企业，每家也有 1/10 的份额；一家退出也会影响其他企业。所以“多小才算完全没有定价能力”在理论上并不容易界定。本讲先接受“价格接受者”这个假设，把复杂情况留到后面的市场结构章节。
02

企业决策：边际收益等于边际成本

完全竞争企业不能影响价格，只能选产量。于是问题变成一个单变量优化：给定 P，选 q 让利润最大。

总收益 TR = P·q，总成本 TC(q)，利润 π = TR − TC。对 q 求导，令边际利润为零：MR − MC = 0。在完全竞争里，企业多卖一个单位，价格不变，所以 MR = P；于是最优决策简化为 P = MC。

1
TR = P · q，  MR = dTR/dq = P（价格外生给定）
2
π(q) = TR(q) − TC(q)，  dπ/dq = MR − MC = P − MC
3
利润最大的一阶条件：P = MC；二阶条件要求 MC 递增
4
“边际利润为零”不是“利润为零”，而是“再多生产一个单位，利润不再增加”

为什么 MC 曲线下的面积不是利润？

把 MC 从 0 到 q 求积分，得到的是可变成本 VC，不是总成本。总成本还要加上固定成本 F。所以利润 = 价格 × q − ∫MC − F。边际成本是总成本的导数，它不包含任何固定成本信息；这也是为什么平均成本图里有固定成本，而边际成本图里没有。

别把 MR = P 当成通用结论

“边际收益等于边际成本”是通用的最优决策规则；但“边际收益等于价格”只在完全竞争市场成立。因为完全竞争企业影响不了价格，不管卖多少，每多卖一个产品的边际收益都是市场价格。到了垄断或寡头，企业要降价才能多卖，MR 就不再等于 P。

03

从 MC 到供给曲线：哪一段才算数？

企业的供给曲线几乎就是边际成本曲线，但只有高于某个“下限”的部分才是。下限是 minATC 还是 minAVC，取决于固定成本能不能收回。

给定价格 P，企业沿着 MC 曲线选择产量。但如果价格太低，企业会选择不生产。问题是：低到什么程度才停产？课件的主线是 P ≥ minATC；在“极短期、固定成本已经沉没”的情形下，下限会降到 minAVC。这两个口径不能混着用。

停止生产点：两种口径，别混用

如果固定成本是机会成本，厂房可退租、设备可转卖，那么停产可以避免固定成本，停止生产点应看 minATC；如果固定成本已经沉没，停产也躲不掉，短期只要 P ≥ minAVC 就继续生产。教授在课上特别提醒：如果固定成本收不回来，硬引入平均可变成本的概念其实没有太大意思；教科书那种“停止生产点 = minAVC”的说法，默认了固定成本沉没。本页把两种假设都摆出来，读图前先看开关。

生产者剩余与利润差一个固定成本

价格线以下、MC 曲线以上的面积是生产者剩余：PS = P·q − VC(q)。而利润 π = P·q − VC(q) − F = PS − F。勾选“显示生产者剩余”，你会看到这块面积比利润矩形大，正好大出固定成本 F。这也是“MC 积分得到的是 VC，不是 TC”的图形版本。

04

短期市场均衡：把 N 条 MC 曲线横着加起来

短期企业数量固定，来不及进入或退出。市场供给是个体供给的水平加总；给定需求，价格由供求相等决定。

这一节的计算套路只有五步，顺序不能乱：先求个体供给，再加总成市场供给，然后联立需求求价格，代回求每家产量，最后算利润。企业成本不一样时，先把各自的供给曲线求出来，再水平加总——不是把价格加起来。

短期亏损，为什么还可能继续生产？

因为固定成本可能已经沉没。停产也躲不掉固定成本，只要价格覆盖平均可变成本（P ≥ minAVC），继续生产虽然会计上亏损，但比停产亏得更少。短期决策看的是“继续生产的损失”与“停产的损失”哪个更小，而不是账面利润是否为正。

为什么 8 家时价格是 3，而不是 4？

因为短期企业数量是外生的，8 家企业只能一起接受市场出清价格。价格 3 低于 minATC = 4，每家企业亏 1.75；但短期内它们来不及退出，只能沿着各自的 MC 曲线生产 1.5。长期来看，亏损会推动部分企业退出，N 下降，价格回升。

05

长期：进入、退出与零利润

长期企业可以自由进出。进入/退出的信号不是会计利润，而是经济利润：π > 0 进入，π < 0 退出，π = 0 停止调整。

长期均衡的条件可以写成一句话：价格等于企业平均总成本的最小值。只要 P > minATC，新企业就会不断进入，把价格压下来；只要 P < minATC，企业就会退出，把价格推上去。最终停在 P = minATC，经济利润为零。

1
企业进入 ⇔ 经济利润 ≥ 0 ⇔ TR ≥ TC ⇔ P ≥ ATC
2
若 P ≥ minATC，企业愿意进入；若 P < minATC，企业退出
3

“零利润”不是“白干”

经济利润为零，意味着企业的收入刚好覆盖全部机会成本，包括企业家自己的时间、资金和厂房本可以得到的其他回报。这时候企业拿的是正常利润，会计利润通常还是正的。零利润只是说：没有额外的超额回报，所以没有企业想再进来，也没有企业想退出。

异质企业呢？如果企业成本不同，长期均衡价格会等于（或略高于）市场中 minATC 最高的那家企业的 ATC。低成本企业获得正利润，但这部分利润其实是资源租金（比如低成本的煤矿），不是“超额利润”吸引新企业进入的信号——因为别人复制不了这块资源。

长期供给曲线：水平，还是向右上倾斜？

长期供给曲线的形状，取决于企业是否同质，以及投入品资源是否有限。需求变化在长期是只改变交易量，还是也改变价格，全看这条曲线。

同质企业、成本不变：长期供给曲线是水平的，高度等于 minATC。需求增加只会让更多企业进入，交易量扩大，长期价格不变。异质企业或投入品有限：长期供给曲线向右上倾斜，需求增加会把高成本企业也拉进来，长期价格上升。

资源有限，也会让长期供给上倾

即使企业看起来是同质的，如果用于该产品的投入品资源是有限的，长期供给曲线也可能向右上方倾斜。煤矿就是典型：需求上升时，成本低的煤矿先被开采；要再扩大产量，就得开采成本更高的煤矿。锂资源也一样：电动汽车动力电池需求增长很快，价格更高时才会有更多高成本的企业进入。课件里还提到 HBM（高带宽内存）作为需求剧烈波动的例子——需求和供给共同作用，经常导致价格显著波动。

长期供给曲线不是严格意义上的函数

水平长期供给曲线是“一个价格对应多个产量”：在这个价格下，企业愿意提供任何市场需求量。所以它更像一条价格—数量关系，而不是 q = f(P) 的函数。长期供给价格由成本决定，与需求无关；需求变化只影响交易量，不改变长期均衡价格——这句话只对同质、成本不变的行业成立。

现实中的“长期”不是很快：需求变化往往难以预测，企业的进出决策取决于它们对市场的预期。需求和供给的共同作用，会让价格在短期显著波动；有时候还会出现自我实现的预期。不要把“长期均衡”理解成“几个月就能到位”。
07

多产品企业、利润来源与方法论

现实中企业往往生产一个产品系列。多产品并不改变“边际成本决定供给”的逻辑；真正让企业赚到正利润的，是成本优势、先发优势和行业周期。

完全竞争的小企业同时生产多个产品时，每个产品的供给曲线仍然由该产品的边际成本曲线决定。各产品市场的短期价格由各自市场的供求平衡决定；长期自由进出使（同质）企业的总经济利润趋于零。长期均衡价格与消费者对各产品的需求有关——产品组合会跟着相对价格调整。

多产品的共同投入会同时压低多个产品的成本。给定厂房，短期 MC 随产量上升；但把规模做大，长期平均成本通常是先降后升的 U 形——先享受规模经济，超过一定规模再进入规模不经济。完全竞争小企业的特点是：规模经济区间很窄，MC 上升很快，产量稍大成本就迅速上升，所以它很难靠扩张占领市场。这也解释了为什么“小”是相对市场规模而言，而不是绝对规模。

课堂讲稿 · 关于理论与企业家的分工

为什么理论要先把企业家“抽象掉”？

成本曲线对应的是生产技术，而生产技术由科技决定。理论假设企业家已经尽了最大努力，把“管理、研发、销售、创新”这些变量先固定住，才能看清价格、产量和进入退出之间的关系。现实中企业家最重要的努力恰恰是研发新产品、以最有效的方式销售；如果生产出来卖不出去，生产 100 个单位也没用。这些创新行为对经济增长很重要，但它们被留在了本课程模型之外。

方法论插一句：我们讨论“价格怎么影响需求量”时，会把其他所有东西固定住。这是静态、孤立、片面的思考方式，也就是“形而上学”的本来含义——它本身是科学思维。现实世界是动态的、全面的：先推导静态关系，再放开其他因素，看它们互相影响、长时间变化。动态问题难在发生的事情太多，还可能出现自我实现的预期。同学们觉得奇怪、新颖的问题，往往就是因为换了一个观察角度。

考前逐条对照
1

把“零利润”当成“会计利润为零”

经济利润为零，意味着收入刚好覆盖全部机会成本，企业拿的是正常利润；会计利润通常还是正的。零利润是“没有超额回报”，不是“白干”。

2

把 MR = P 当成通用结论

MR = MC 是通用的；MR = P 只在完全竞争成立。垄断企业要多卖就得降价，MR < P。

3

把 MC 曲线下的面积当成利润

∫MC dq = VC，不含固定成本。利润 = P·q − ∫MC − F。图形上，MC 以上的价格面积是生产者剩余，减去 F 才是利润。

4

把停止生产点一律画在 minAVC

要看固定成本是否沉没：可收回时看 minATC；已沉没时短期看 minAVC。两种口径不能混用。

5

把长期供给曲线当成普通函数

水平长期供给是“一个价格对应多个产量”，不是 q = f(P)。长期价格由成本决定，需求只决定交易量（同质、成本不变时）。

6

认为企业数量必须是整数

理论允许分数企业，N* = 5.5 是连续解；整数约束是应用细节，取小于 N* 的最大整数，5 家正利润、6 家亏损。

7

认为短期亏损就该立刻停产

固定成本沉没时，只要 P ≥ minAVC，继续生产比停产亏得少。短期看“继续 vs 停产”的损失比较，长期才看是否退出。

随堂六问

选一个答案，立刻看解释。做错没关系，重点是知道为什么。

1. 已知 TC = 4 + q²，市场价格 P = 6。利润最大化的产量与利润是？
P = MC：2q = 6 ⇒ q = 3；π = 6×3 − (4 + 9) = 18 − 13 = 5。也可以用 π = P²/4 − 4 = 36/4 − 4 = 5。
2. 上题中，若固定成本 4 已经沉没，价格降到 P = 3，短期企业应该？
看可变成本：TC = 4 + q² 时 AVC = q，minAVC = 0。P = 3 > 0，继续生产可以覆盖全部可变成本，并收回一部分固定成本；停产反而亏掉全部 4。注意：长期 P < minATC = 4，企业会退出。
3. 4 家企业时市场均衡价格是 5，8 家企业时是 3。下列说法正确的是？
算利润：4 家时 q = 2.5，π = 5×2.5 − (4 + 6.25) = 2.25；8 家时 q = 1.5，π = 3×1.5 − (4 + 2.25) = −1.75。企业越多，总供给越大，价格越低。
4. 长期均衡中，若企业同质，长期供给曲线是？
同质企业：长期价格被钉在 minATC，所有企业零利润。需求变化只改变交易量，不改变长期价格，所以长期供给是水平的。异质企业或资源有限时，才会向右上倾斜。
5. 下列哪个市场最接近完全竞争？
产品同质、买家多、单个企业小：黄金最接近。不同金矿成本不同，但产出的黄金一样，价值高、运输成本相对低。智能手机、汽车、咨询都高度差异化，企业有定价权。
6. 长期均衡企业数量 N* = 5.5，考虑整数约束应取？
取小于 N* 的最大整数：5 家时还有正利润，但没有更多企业进入；6 家时亏损，会有企业退出。所以整数约束下均衡是 5 家。

衔接：零利润之后，利润从哪里来

第 11 讲说“长期经济利润为零”。这句话不是“企业都不赚钱”，而是“在自由进入、产品同质的市场里，超额回报会被竞争抹平”。今天先把这个容易误读的结论补完整。

把“经济利润”拆开看：利润 = 收入 − 全部机会成本。机会成本里包含企业把资金、产能、时间投在别处能拿到的回报。所以“零经济利润”意味着企业拿到了正常回报，而不是白干。反过来说，只要某处有别人进不来的高回报，经济利润就会留下来。

“竞争性企业的利润确实比较低。但经济利润是考虑了所有机会成本后的利润。如果在其他领域有很高的机会收益，那么企业在这里的实际经济利润就会受到影响。”

课堂讲稿 · 第 12 讲开场
短期技术壁垒：HBM

AI 高端内存客户少、门槛高。短期内别人进不来，价格和利润都很高；等技术成熟、竞争者进入，超额利润才会慢慢回归。它仍然是竞争市场，只是“进入”需要时间。

机会成本很高，利润也可能很高

原来生产普通内存的产能转向高端内存，放弃的普通内存收益就是机会成本。只有当前利润高于这笔机会成本，才有真正的经济利润。

周期：踩对时点

完全竞争市场也可能有周期。价格高时扩产，供给滞后到达，价格暴跌；供给收缩后价格再回升。能看准节奏的人赚钱，但精准踩周期非常难。

成本优势

进入壁垒

资源、专利、牌照、规模经济、网络效应、策略性阻止——只要别人进不来，利润就不会被磨平。

周期与时机

在供给滞后、价格波动大的市场里，进入时点本身就能创造利润，也可能吞掉利润。

产品不完全替代，企业就有一点定价权；但自由进入仍会把长期利润压向零。

01

垄断：唯一供给者，需求就是市场需求

垄断是市场结构的另一个极端：市场上只有一家企业，产品没有相近替代品，它面对的需求曲线就是整个市场的需求曲线。

严格意义上的垄断要同时满足三件事：唯一供给者、没有相近替代品、没有潜在竞争。现实里完全满足的不多，但“接近垄断”的市场不少。理解垄断，重点不是背定义，而是看进入壁垒从哪里来。

① 唯一供给者

整个市场的供给由一家企业完成。它不需要看别人的价格，因为它就是市场。

② 无相近替代品

消费者找不到功能接近的替代方案。替代品越少，需求越不敏感，定价空间越大。

③ 面临市场需求

企业面对的不是“剩余需求”，而是整条市场需求曲线：想多卖，就得降价。

四类进入壁垒

垄断的来源，几乎都能归到这里
1 · 关键资源或技术秘密

独占矿山、专利配方、工艺诀窍。别人不是不想进，是拿不到关键投入。

2 · 政府限制

专利、版权、特许经营、专卖制度。政府用法律把竞争者挡在门外，通常附带公共目标。

3 · 规模经济或网络效应

产量越大平均成本越低，新进入者起步规模小、成本高；或者用户越多产品越有价值，后来者难以撬动。

4 · 在位者策略性阻止

低价倾销、独家协议、过度产能、收购潜在进入者。壁垒不是天然的，而是被“做”出来的。

“自然垄断”不是严格意义上的垄断

自然垄断描述的是成本结构：相比两家或更多企业，一家企业生产全部产量的总成本更低。自来水、电力、有线电视的管网就是典型——重复铺一套管网是浪费。它可能只有一家企业，但逻辑不是“把别人挡住”，而是“一家做更便宜”。因此政策工具也不同：与其拆开，不如发牌照 + 价格监管。

垄断者不是“想定多高就定多高”

它仍然受需求曲线约束：价格越高，买的人越少。垄断的真正特征是不用按 P = MC 定价，而不是没有约束。接下来我们就把这条约束画出来。

02

垄断定价：为什么 MR 低于 P

完全竞争企业多卖一单位，价格不变，所以 MR = P。垄断企业多卖一单位，必须对“所有单位”降价，所以 MR < P，而且 MR 曲线比需求曲线更陡。

先把这个取舍讲清楚。你想多卖，就得把价格降下来；降价不是只作用于“新增的那一单位”，而是作用于全部已卖出的单位。所以多卖一单位带来的净收入，一定低于当前价格。

1
总收益：R(Q) = P(Q) · Q，其中 P(Q) 是市场需求曲线。
2
边际收益：MR = P + Q · (ΔP/ΔQ)。因为 ΔP/ΔQ < 0，所以 MR < P。
3
线性需求 P = A − Q 时：R = (A − Q)Q，MR = A − 2Q。MR 的斜率是需求的两倍。
4
利润最大化：令 MR = MC。若 MC = c，则 Qm = (A − c)/2，Pm = (A + c)/2。
5
利润：π = (Pm − c)Qm − F = (A − c)²/4 − F。固定成本不改变 Qm 与 Pm，只改变利润。

垄断价格随 MC 上升

Pm = (A + c)/2。成本上升，产量下降、价格上升；但价格上升幅度只有成本上升的一半。

固定成本不影响定价

F 不进入 MR 和 MC，所以不改变 Qm、Pm。它只改变利润，以及“值不值得进入”。

净利润为负就不进入

如果预期净利润为负，垄断企业不会开展经营，或在长期退出。垄断不等于一定赚钱，需求太小、成本太高一样会亏。

03

福利损失：价格高于 MC 的那一部分

统一定价下，垄断产量低于社会最优产量。少做的那部分交易，本来能让买方支付意愿高于边际成本，双方都能获益，却没有发生。

社会最优的标准是 P = MC：只要有人愿意付的钱高于多生产一单位的成本，这笔交易就该发生。垄断者停在 MR = MC，此时 P > MC，说明还有一批“愿意付、也付得起成本”的交易被挡住了。这块被挡住的净收益，就是无谓损失。

负面福利影响

管理松弛、服务较差

没有竞争压力，内部管理水平和消费者服务质量往往较低。省下来的成本不一定变成价格下降，可能变成组织冗余。

创新意识较弱

既有利润受壁垒保护，企业缺乏“不创新就出局”的压力。但这条不能绝对化，下面还有反例。

偏向“轻资产”

讲稿提到，垄断企业可能过度倾向于轻资产运营。它不需要靠重资产效率来竞争，资源更容易流向维持壁垒或金融资产。

政治经济学风险

经济权力集中可能转化为游说、监管俘获等影响力，进一步加固壁垒。

正面影响

充分利用规模经济

大产量摊薄固定成本，在自然垄断行业尤其明显。拆成多家反而总成本更高。

应对行业层面挑战

资金、研发、抗风险能力更强，能承担单个小企业承担不了的长期项目。

研发资源更丰富

可投入研发的资源较多。但注意：实证研究发现，研发投入最多的既不是完全竞争企业，也不是垄断企业，而是寡头市场中的企业。

所以垄断不是“一律坏”

判断要看：壁垒是否必要、规模经济是否显著、企业是否在用壁垒阻止别人创新。政策也因此分成四种工具。

针对垄断的四类公共政策

反垄断法 · 政府规制 · 公有制 · 不作为
反垄断法

打击垄断行为，例如通过不正当手段排挤对手、价格合谋、滥用市场支配地位。不是打击“垄断状态”本身。

政府规制

常用于自然垄断行业：发牌照授权少数企业运营，同时对价格、接入条件、服务质量进行约束。

公有制

由政府直接拥有和经营。适合公共目标压倒商业目标、且难以通过合同监管的领域。

不作为

有时干预成本高于收益，或市场会通过技术替代自行打破垄断。钻石被人造钻石打破就是例子。

关键区分：如果一个企业靠技术突破、成本优势在竞争中胜出并形成垄断，这是合法的；反垄断法针对的是“用不正当手段维持或扩张垄断地位”的行为。
自然垄断的规制逻辑：电网这类行业，重复建设不经济，所以政府发放独家运营权，但价格受严格监管。典型例子是国家电网：独家运营 + 价格监管，而不是强行拆成多家互相铺线。
04

区别定价：把消费者剩余拿回来

统一定价只能收一个价，愿意多付的人也只付同样的钱。如果企业能对不同人收不同价，就可以把一部分消费者剩余转成利润，甚至把无谓损失也吃掉。

区别定价（价格歧视）的前提只有一个，但非常关键：消费者之间不能转售。如果能低价买进、高价卖出，套利会把所有价格拉平，区别定价就失效了。在这个前提下，企业按支付意愿分层定价，通常能提高利润，但也有操作成本。

Ⅰ

一级：因人而异

按每个人的支付意愿定价，理论上可以做到“一人一价”。现实近似是大数据杀熟：根据你的消费记录、设备、位置给出不同价格。需要极强的信息能力。

Ⅱ

二级：信息不对称

企业不知道你是谁，但设计一套菜单让你自己选。例如折扣券、不定期促销、多档套餐。愿意花时间找券的人付低价，赶时间的人付高价。

Ⅲ

三级：分群体

按可观察的群体特征定价。例如地区价格、学生折扣、老人折扣。群体之间的转售难度决定了这种定价能不能维持。

什么时候增进福利：如果区别定价把原本不发生的交易做成了（产量从 Qm 扩到 Q*），总剩余增加；如果只是把同一批交易剩余从消费者转到企业，总剩余不变。

什么时候降低福利

如果区别定价主要用来阻止转售、锁定客户、抬高对弱势群体的价格，或者消耗大量资源用于甄别消费者，福利可能下降。方向不能一概而论。

为什么“不能转售”是前提

学生票如果能随便转卖给非学生，学生价就维持不住；药品如果地区价差过大，就会出现“串货”。所有区别定价的稳定性，都建立在某种形式的隔离之上：身份验证、地域限制、产品版本差异、合约限制。

05

垄断竞争：有定价权，但进得来

每个企业卖有差异的产品，面对的是“扣掉其他竞争者之后”的剩余需求，曲线向下倾斜；但市场自由进出，正利润会引来新品牌。

垄断竞争把两个特征放在一起：有定价权（产品有差异，需求曲线向下倾斜），自由进出（长期利润被磨平）。它既不是完全竞争的价格接受者，也不是垄断的“进不来”。

剩余需求

企业面临的不是整个市场需求，而是扣除其他竞争者供应后的剩余部分。竞争者越多，这条曲线越往里移。

短期：可能赚，也可能亏

给定需求曲线，按 MR = MC 选产量，再沿需求曲线定价。价格高于 ATC 就盈利，低于 ATC 就亏损。

长期：自由进出

正利润吸引新企业进入，剩余需求左移；亏损推动在位企业退出，剩余需求右移。直到利润归零。

完全竞争（长期）

需求水平线切于 ATC 最低点：P = minATC，产量达到成本最低规模。

垄断竞争（长期）

需求曲线切于 ATC 下降段：π = 0，但 P > MC，且 q* 小于最低成本产量。

过剩产能

垄断竞争企业的产量低于使 ATC 最低的产量。多出来的产能不是“浪费”，而是产品差异的代价：为了差异化，每家规模都不够大。

价格高于 MC

长期零利润不等于有效率。P > MC 说明还可以多生产一些让双方受益，但企业没有动力这么做。

进入的外部性

新企业进入会降低价格，对消费者有利；同时抢走在位企业的生意，对同行不利。净外部性不确定，所以企业数量可能高于也可能低于社会最优。

规模经济显著时

过度进入的问题可能比较严重：每家都太小、成本太高。此时可能需要政府干预，限制低水平重复进入。

广告：创造价值还是误导消费者？广告可以提供价格、功能、位置等信息，降低搜寻成本；也可能通过制造虚假差异、放大焦虑来改变偏好。判断标准不是“有没有广告”，而是“它有没有让消费者做出更符合自身利益的选择”。

短期可能有利润；长期 D 与 ATC 相切，π = 0，但 P > MC、产能过剩。

垄断：价格自己定，且进不来

长期正利润；P > MC、产量不足；政策工具是反垄断、规制、公有化或不作为。

把“零利润”和“有效率”分开

垄断竞争长期利润为零，但它并不像完全竞争那样有效率：价格仍高于边际成本，产量仍低于社会最优。零利润只说明“没有超额回报”，不说明“资源配置最优”。这是这一讲最容易混的一处。

八个最容易错的点

考前逐条对照
1

把反垄断法当成“反对垄断状态”

反垄断法打击的是垄断行为：合谋、掠夺性定价、滥用支配地位、排他协议。靠技术突破赢得的市场地位本身不违法。

2

认为垄断者可以随意定价

它仍受需求曲线约束。定价越高，销量越少；最优价格是“MR = MC 后沿需求曲线读出来的”，不是想定多少定多少。

3

把 P = MC 套到垄断企业身上

P = MC 是完全竞争和社会最优的条件。垄断用 MR = MC 定产量，然后按需求曲线定价，所以 P > MC。

4

把 MR 当成价格

只有完全竞争才有 MR = P。垄断多卖一单位要对全部单位降价，MR < P；线性需求下 MR 斜率是需求的两倍。

5

把“自然垄断”当成严格意义的垄断

自然垄断是成本结构：一家生产总成本更低。它不一定是靠壁垒把别人挡住，政策上也更常用“牌照 + 价格规制”而不是拆分。

6

认为区别定价一定提高社会福利

如果它扩大了产量，总剩余增加；如果只是把同一批交易的剩余从消费者转到企业，总剩余不变；如果用于封锁市场或甄别成本过高，也可能下降。

7

认为垄断竞争长期零利润就等于完全竞争

零利润只说明没有超额回报。垄断竞争仍有 P > MC、产量低于社会最优、存在过剩产能。

8

认为垄断企业研发投入最多

实证研究发现，研发投入最多的既不是完全竞争企业，也不是垄断企业，而是寡头市场中的企业。竞争压力和资源能力需要同时具备。

随堂八问

选一个答案，立刻看解释。做错没关系，重点是知道为什么。

1. 垄断企业面临的需求曲线是？
唯一供给者：市场上只有它一家，所以它面对的就是整个市场需求。水平需求是完全竞争，剩余需求是垄断竞争，垂直线不是标准的需求曲线。
2. 已知 P = 16 − Q，C(Q) = 6 + 5Q。连续情形下的最优产量与价格是？
MR = MC：MR = 16 − 2Q，MC = 5，解得 Q = 5.5；代回需求 P = 16 − 5.5 = 10.5。利润 = 5.5×5.5 − 6 = 24.25。表格里 Q = 5 和 Q = 6 并列 24，是整数约束下的结果。
3. 为什么垄断企业的边际收益低于价格？
降价作用在全部销量上：多卖一单位带来价格 P，但同时让前面所有单位都少收 ΔP。两项相抵，净收入低于 P。完全竞争企业降价不影响市场价，所以 MR = P。
4. 垄断的无谓损失来自哪里？
少做的交易：在 Qm 到 Q* 之间，买方的支付意愿高于边际成本，本来双方都能获益，却没有发生。这块净收益的消失就是无谓损失。利润高本身是转移，不是损失。
5. 反垄断法主要针对的是？
行为而非状态：靠技术突破、成本优势在竞争中胜出并形成垄断，是合法的。反垄断法针对合谋、掠夺性定价、滥用支配地位等行为。自然垄断则更多用规制处理。
6. 关于自然垄断，下面哪个说法正确？
成本结构：自来水、电网、有线电视的管网重复建设不经济，一家做总成本更低。所以政策上常发牌照授权独家经营，同时对价格进行监管，而不是强行拆成多家。
7. 一级区别定价（完全价格歧视）的结果是？
按支付意愿逐单位定价：每单位都收到买方最高愿意付的价格，CS 变为 0；只要支付意愿高于 MC 就继续卖，产量到 Q*，DWL 消失。总剩余是否增加，取决于产量有没有扩大。
8. 垄断竞争长期均衡的特征是？
自由进出 + 产品差异：进出把需求曲线推到与 ATC 相切，P = ATC，π = 0；但切点在 ATC 最低点左侧，所以 P > MC，产量低于最低成本规模，存在过剩产能。

00

衔接：从“单人最优”到“互相预判”

前面的消费者、完全竞争企业、垄断企业，做的都是同一类题：给定价格或成本，选一个最优数量。博弈论多了一个变量——别人的选择也在你的收益函数里。

这不是“多背一个定义”，而是换一种思考方式。单人决策里，约束来自市场；策略互动里，约束来自对方也会理性地回应你。你不能只问“我想干什么”，还要问“我这么做，他会怎么接”。

单人最优化：只看自己

给定市场价格 P、成本函数 C(Q)，企业选 Q 让利润最大。价格是外生参数，不会因为“企业怎么想”而改变。完全竞争、垄断定价都属于这一类。

策略互动：收益取决于双方

你的收益写成 u1(s1, s2)，同时取决于你选什么、对方选什么。对方也在解同一个问题，所以“最优”必须是相互一致的。

“博弈讨论的是策略互动。你不光要考虑外部世界，还要考虑别人会怎么反应。每个人独立选择自己的策略，目标是让自己的收益最大。”

博弈的三要素

把“故事”翻译成可计算的表
① 参与者 N

谁在做决策？两个企业、两个嫌疑人、你和对手。每个参与者都有自己的目标。

② 策略集 Si

每个人能选什么？降价/不降价、认罪/否认、石头/剪刀/布。策略要写全，不能漏掉“什么都不做”。

③ 收益函数 ui

每种策略组合下，每个人得到多少。收益不一定是钱，也可以是利润、工资、效用、快乐。

一句话：博弈 = 参与者 + 策略集 + 收益函数。把这三样写清楚，后面的“占优”“均衡”才有对象可谈。

02

占优策略：不管别人怎么选，我都选它

有些策略不需要猜对方：无论对方选什么，它都更好。这样的策略叫占优策略。它是博弈论里最省事的解，但并不是每个博弈都有。

先把两个层次分开：“在这一格，我的收益更高”是局部比较；“无论对方选什么，这个策略都更好”才是占优。占优策略是横向比较一整列（或一整行），不是只看一个格子。

强占优：一定选

只要发现强占优策略，理性玩家就会选它。被强占优的策略绝不会出现在任何纳什均衡里。

弱占优：不一定唯一

弱占优策略也值得选，但被弱占优的策略仍可能出现在某个纳什均衡里——后面囚徒困境的“弱占优版”会看到。

没有占优怎么办

很多博弈两个人都没有占优策略。这时不能偷懒，要逐格比较最优反应，进入下一节的纳什均衡。

最常见的误读：把“这一格收益低”当成“被占优”

占优是整行 / 整列的比较。某个格子里收益低，可能只是因为对方选了克制你的策略；换个格子，同样的策略也许是最优的。判断占优，必须固定“对方选什么”，再比较“我选什么”。

为什么占优策略这么有用

它把“猜对方”这件事消掉了。只要 A 有强占优策略，你不必知道 B 会怎么选，就能先确定 A 的行为；确定之后，B 的问题退化成一个单人最优化。很多复杂博弈的第一步，就是找这种“不需要猜”的策略。

03

纳什均衡：谁都不想单独改变

如果没有占优策略，就要找“相互一致”的状态：给定对方的选择，我当前的选择已经是最优；对方也一样。这样的策略组合，就是纳什均衡。

如果所有人都预判对了别人的选择，谁还会有动机偷偷改？

纳什均衡的定义只有一句话：给定其他人的策略不变，没有任何一个参与者能通过单方面改变自己的策略而严格提高收益。注意三个关键词：给定别人不变、单方面、严格提高。少了任何一个，判断都会跑偏。

定义式：ui(si*, s-i*) ≥ ui(si, s-i*) 对所有 si 成立。注意是“大于等于”，允许无差异。
4
存在性：有限博弈至少存在一个纳什均衡（可能要用混合策略）。这是纳什 1950 年证明的结果，也是它在经济学里地位这么高的原因。
纳什均衡是“稳定状态”

不是“最好的结果”，而是“没有人想单独改”。它更像一个自我实现的预期：大家都相信对方会这么选，于是自己也这么选。

可能不唯一

同一场博弈可以有两个甚至更多纳什均衡。哪个会发生，取决于历史、预期、沟通、焦点（focal point）。

可能不是帕累托最优

囚徒困境就是典型：双方都认罪是纳什均衡，但双方都否认对两人都更好。稳定和效率是两件事。

“强纳什均衡”是另一个更强的要求

普通纳什均衡只排除单方面偏离。如果连“两个人联合起来一起改”都找不到更好的结果，才叫强纳什均衡。课堂里提到的“强化版本”就是这个方向；考试如果只写“纳什均衡”，默认是普通定义。

检查动作：找到一个候选格子后，分别问两个问题——“A 单独改会更好吗？”“B 单独改会更好吗？”两个答案都是“不会”，它才是纳什均衡。只检查一方，是最常见的漏判。
04

囚徒困境：个体理性，集体糟糕

两个嫌疑人分别关押、不能串供。每个人都有一条“无论对方怎么做都更好”的策略——认罪。结果两个人都认罪，却比两个人都否认更糟。

囚徒困境是博弈论最著名的例子，因为它把一句直觉说清楚了：每个人都做对自己最有利的选择，加在一起不一定对所有人最好。它不是“人不理性”，恰恰是“每个人都很理性”的结果。

囚徒困境在现实里长什么样

结构相同，故事不同
军备竞赛

对方扩军，我不扩就吃亏；对方不扩，我扩就占优。结果双方都扩，安全没增加多少，成本却上去了。

价格战 / 卡特尔

两家企业约定维持高价，但每家都想偷偷降价抢市场。结果价格被拉到低位，利润一起变薄。

公共资源

每个人都想多用一点公共牧场、渔业资源、地下水；单独看都合理，合起来就是过度使用和枯竭。

广告战

一家投广告，另一家不投就丢份额；两家都投，份额未必变，但成本都上升。广告的“创造价值”部分因此更难判断。

怎么走出困境

改变博弈，而不只是劝人善良
① 重复博弈

如果以后还会见面，今天的背叛会招来明天的报复。长期关系让“合作”变得值得，声誉和惩罚机制开始起作用。

② 有约束力的协议

合同、监管、行业规则。把“偷偷背叛”的收益降下来，或者让背叛付出代价，均衡就可能移动。

③ 改变收益结构

罚款、奖励、产权界定、信息公开。囚徒困境不是“人性问题”，很多时候是“规则问题”。

④ 声誉与信任

在重复互动中，愿意合作的人会积累声誉；但声誉也可能被用来维持排他性联盟，方向不总是好的。

考试提醒：“囚徒困境有纳什均衡”不等于“合作不可能”。单次博弈的结论，不能直接套到重复博弈、有合同、有监管的场景。题目问的是哪一种，要先看清。

弱占优版：为什么（否认, 否认）也能成为纳什均衡

把（否认, 否认）的收益从 (−1, −1) 改成 (0, 0) 后，给定对方否认，认罪得 0、否认也得 0——A 没有严格动机改。于是（否认, 否认）也满足“没有人想单方面严格改进”，成为第二个纳什均衡。此时认罪只是弱占优：对方否认时，认罪和否认打平。这就是“被弱占优的策略仍可能出现在纳什均衡里”的具体例子。

05

混合策略：没有纯策略均衡怎么办

石头剪刀布没有“永远出石头”的纯策略均衡：你出石头，对手就出布；你改出布，对手就出剪刀。稳定状态只能是把三个策略按一定概率混着出。

混合策略不是“随机瞎选”，而是一组概率分布。它的作用不是让你更幸运，而是让对手无法通过针对某一个策略占便宜。当对手对你所有纯策略都无差异时，你就没有可被利用的破绽。

1
混合策略：在纯策略集合上给每个策略分配一个概率，pi ≥ 0，且 Σ pi = 1。比如 (1/3, 1/3, 1/3) 是石头剪刀布的一个混合策略。
2
支撑：概率严格大于 0 的那些纯策略。上例的支撑是 {石头, 布, 剪刀}；如果你只出石头和布，支撑就是 {石头, 布}。
3
期望收益：E[ui] = Σs p(s) · ui(s)。把每个格子出现的概率乘以对应收益，再加总。
4
均衡条件：在混合策略纳什均衡里，对手对支撑中每个纯策略的期望收益都相等；否则对手会只打那个让你更难受的策略。
纯策略均衡可能不存在

石头剪刀布、猜硬币都没有纯策略纳什均衡。有限博弈的均衡可能存在，但要在“混合策略”里找。

混合不是随机乱来

概率是为了让对手无差异，不是“随便按一下”。在均衡里，每个被使用的纯策略都给对手同样的期望收益。

猜硬币：各 1/2

两人同时选正面/反面，一人猜中赢、猜错输。没有纯策略均衡，混合均衡是各 1/2——和石头剪刀布的 1/3 是同一套逻辑。

为什么要让对手无差异：如果对手发现你出石头的概率更高，他就会改出布；只要存在一个“更赚”的纯策略，他一定会选它。只有当他对所有可选策略的期望收益一样时，他才没有动机针对你——这就是混合策略均衡的直觉。
06

找均衡的五步法，与八个常见误区

考试里的博弈题，难点通常不是算，而是“先看什么、后看什么”。把步骤固定下来，比临场凭感觉稳。

拿到一个 2×2（或 3×3）矩阵，先不要急着找“看起来最好的格子”。按下面的顺序走：写清楚 → 找最优反应 → 划线 → 检查偏离 → 没有纯策略再上混合。

1
写清楚：行是谁、列是谁，每格第一个数字归谁。把策略名写在表头，不要只写“策略 1 / 策略 2”。
2
找最优反应：固定每一列，找行玩家的最大收益；固定每一行，找列玩家的最大收益。逐列、逐行做，不要跳。
3
划线：把行玩家的最优反应用一种线标出，列玩家的用另一种。两种线都出现的格子，就是纯策略纳什均衡。
4
检查偏离：对每个候选格子，分别问“A 单独改会更好吗”“B 单独改会更好吗”。两个都不会，才是纳什均衡。
5
没有纯策略：设混合策略概率，令对手在各纯策略上的期望收益相等，解方程；再检查概率是否非负、和为 1。

把五步法走一遍

用第 2 节的不对称矩阵
步骤做什么在这个例子里
1确认收益顺序A 是行玩家，每格第一个数字归 A；B 是列玩家，第二个数字归 B。
2找 A 的最优反应B 选左：上 4 > 下 2；B 选右：上 5 > 下 2。A 的占优策略是“上”。
3找 B 的最优反应A 选上：左 3 > 右 1；A 选下：右 4 > 左 2。B 没有占优策略。

结论：这个博弈有唯一纯策略纳什均衡 (上, 左)，收益 (4, 3)。注意 A 的占优策略让问题变简单，但 B 仍然要看 A 的选择才能决定左/右。

八个最容易错的点

考前逐条对照
1

把纳什均衡当成“对所有人最好”

纳什均衡是“没有人想单独改”，不是“总收益最大”。囚徒困境里双方都认罪是均衡，但双方都否认对两人都更好。

2

认为每个博弈都有占优策略

很多博弈两个人都没有占优策略。没有占优策略不等于“不会做”，而是要用最优反应和划线法。

3

把“这一格收益低”当成“被占优”

占优是整行/整列的比较：固定对方每一个策略，我选它都更好。只看一个格子，说明不了占优。

4

忽略弱占优

弱占优允许相等。被弱占优的策略仍可能出现在纳什均衡里；把（否认, 否认）改成 (0, 0) 后，它就成了第二个均衡。

5

认为纳什均衡一定唯一

协调博弈可以有两个甚至更多均衡。题目如果问“哪个会发生”，要结合历史、预期、沟通或焦点来讨论。

6

认为纯策略均衡一定存在

石头剪刀布、猜硬币都没有纯策略均衡。有限博弈保证的是“至少有一个混合策略均衡”，不是“一定有纯策略均衡”。

7

把混合策略理解成“随机瞎选”

均衡概率是为了让对手无差异。石头剪刀布的 1/3 不是“随便出”，而是“让对手出什么都一样”。

8

把单次博弈的结论直接套到长期关系

囚徒困境在单次、匿名、无合同的情况下成立。重复博弈、声誉、合同、监管都会改变收益结构，合作可能变得可持续。

一个通用的检查清单

① 收益顺序写对了吗？② 每个参与者的策略集完整吗？③ 最优反应是逐列/逐行找的吗？④ 候选格子两边都检查偏离了吗？⑤ 没有纯策略时，概率非负、和为 1 吗？⑥ 最后问一句：这个均衡是“稳定”，还是“最好”？把“稳定”和“效率”分开说，答案会清楚很多。

07

速查、易错点与随堂自测

把定义压缩成六张卡片，再用八道题检查自己是不是真的会判断。做题时先写收益顺序，再划线，最后检查偏离。

博弈三要素

参与者 N
策略集 Si
收益 ui(s1, …, sn)
G = {N, {Si}, {ui}}

强占优

对所有 s−i：
ui(si, s−i) > ui(si′, s−i)
严格大于，没有例外

对所有 s−i：
ui(si, s−i) ≥ ui(si′, s−i)
允许相等；可能仍有均衡

对所有 si：
ui(si*, s−i*) ≥ ui(si, s−i*)
没有人想单方面严格改进

E[ui] = Σ p(s) ui(s)
支撑 = {si : pi > 0}
均衡时对手对各纯策略无差异

随堂八问

选一个答案，立刻看解释。做错没关系，重点是知道为什么。

1. 博弈论与单人最优化的核心区别是？
策略互动：单人最优化里，价格或成本是外生参数；博弈里，收益函数同时包含双方策略，别人也在解同一个问题。参与者可以多于两个，也不一定是零和。
2. 2×2 矩阵某格写着 (5, 2)，通常表示？
第一个数字归行玩家：这是矩阵书写的惯例。读反顺序是博弈题最常见的低级错误；先确认行是谁、列是谁，再读数字。
3. 强占优策略的定义是？
整行/整列比较：强占优要求对每一个对方策略都严格更好，不是只看一个格子。它不一定让总收益最大，也不等于纳什均衡本身，但双方都选强占优策略时，会形成一个纳什均衡。
4. 被强占优的策略会出现在纳什均衡中吗？
严格更好：如果存在另一个策略在所有情况下都严格更好，那么在任何候选均衡里，参与者都有动机换过去，所以原策略不可能稳定。弱占优不一样：被弱占优的策略仍可能出现，因为某些情况下两者打平。
5. 标准囚徒困境的纳什均衡是？
占优策略均衡：无论对方怎么选，认罪都严格更好，所以双方都认罪。双方都否认虽然各得 −1、帕累托更优，但给定对方否认，我有动机改成认罪拿 0，因此不稳定。
6. 纳什均衡一定是帕累托最优吗？
稳定 ≠ 效率：纳什均衡只排除单方面偏离，不排除双方联合改进。囚徒困境的 (认罪, 认罪) 是纳什均衡，但 (否认, 否认) 让两人都更好，只是每个人都不愿单方面维持它。
7. 石头剪刀布的混合策略纳什均衡是？
让对手无差异：各 1/3 时，对手出石头、布、剪刀的期望收益都是 0。任何偏离都会让某个纯策略变得有利可图，对手就会针对你。所以 1/3 是唯一混合均衡。
8. 如果一个博弈没有纯策略纳什均衡，应该？
混合策略：设概率、算期望、令对手无差异，再解方程并检查概率非负、和为 1。有限博弈至少存在一个混合策略纳什均衡；没有纯策略均衡不代表没有均衡。

跨讲对照：同一个最优化，三种约束

完全竞争、垄断、垄断竞争与博弈，不是四套孤立知识，而是“给定约束，选最优”在不同市场环境下的四次变形。

三条公式链

价格接受者

P = MR
↓ 利润最大化 MR = MC
P = MC

多卖一单位不影响价格，所以边际收益就是价格。价格由市场给定，企业只决定产量。

价格制定者

P > MR
↓ 利润最大化 MR = MC
P > MC

多卖一单位必须降价，边际收益低于价格；MR = MC 决定产量，价格再回到需求曲线上读。

策略互动

ui(si, s−i)
↓ 给定 s−i 选最优
si* ∈ BRi(s−i*)

双方互为最优反应时，没有人能靠单方面改变策略提高收益，这就是纳什均衡。

三条因果，连起三讲

竞争企业为什么不猜对手？

价格由市场给定，企业是价格接受者；自己的产量不影响价格，所以 MR = P，最优条件是 P = MC。

垄断者为什么 P > MC？

多卖一单位必须降价，MR < P；MR = MC 只决定产量，价格要沿需求曲线向上读，于是 P > MC。

寡头为什么要划线？

每个人的最优选择都取决于对方；只有双方互为最优反应，才没有单方面改变策略的动机。

统一做题顺序
  1. 先认结构：企业数量、产品是否有差异、进入是否自由。
  2. 再定规则：价格接受 → P = MC；能定价 → MR = MC；互相依赖 → 最优反应 / 划线法。
  3. 最后查长期与福利：自由进入时利润趋于 0；进入受阻时利润可留存；比较 P 与 MC 判断无谓损失；博弈再看均衡是否帕累托最优。

写答案时先写“谁在选、能选什么、约束是什么”，再代公式。三讲的所有题都可以套这个顺序。
